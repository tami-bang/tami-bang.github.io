# Tami's Dev Blog

기술 공부 기록과 포트폴리오를 정리하기 위한 개인 개발 블로그입니다.

## 목적

- Python, C, Network, Backend, Frontend, AI 학습 내용 정리
- 공부한 내용을 프로젝트에 적용한 과정 기록
- GitHub 포트폴리오와 연결되는 개인 기술 블로그 구축

## 주요 페이지

- `/` : 메인 페이지
- `/blog` : 공부 기록
- `/projects` : 프로젝트 정리
- `/about` : 소개 페이지

## 기술 스택

- Next.js
- TypeScript
- Tailwind CSS
- GitHub Pages

## 참고 방향

Josh Comeau 블로그의 밝은 색감, 큰 타이포그래피, 카테고리 중심 구성을 참고하여  
개인 공부 기록과 포트폴리오 목적에 맞게 재구성합니다.

## 실행 방법

```bash
npm install
npm run dev
